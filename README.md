免 Root 安卓 DNS 广告过滤器，Android 13 及以上。默认使用完整 anti-AD 通用域名库，保留精简模式、白名单、最近任务隐藏和诊断功能。

## 安装

最新安装包：[QuietStart-0.3.2.apk](https://github.com/dskiiii/QuietStart/releases/download/v0.3.2/QuietStart-0.3.2.apk)。直接覆盖安装，打开静启并开启过滤，等页面显示“过滤运行中”。旧版卡在“正在暂停”时无需等待即可安装新版。规则版本和数量在“设置 → 规则与白名单”查看。首次授权系统 VPN，会替换其他 VPN。

在小米设置中允许后台自启动，省电策略设为无限制。点击“收起页面，继续过滤”后最近任务不留卡片，桌面图标仍保留。系统仍可显示通知、VPN 标识和运行服务。清理后台和系统省电仍可能停止服务。

可在系统 VPN 设置启用“始终开启 VPN”；**不要启用“阻止不使用 VPN 的连接”**，本软件只路由 DNS，启用该选项可能断网。若要长期暂停，可能还需关闭系统的“始终开启 VPN”。

## 通用规则

- 默认随包完整 anti-AD：105719 个不同域名，版本 20260908053823。合并旧版 39 条精选规则；最终去重数量在运行时显示。
- 点击“从 GitHub 更新完整规则”才联网下载，不后台定时下载。HTTPS 固定源，验证格式/大小/数量，原子保存；失败保留旧规则，缓存损坏回退随包快照。更新无需重装软件。
- 完整库覆盖广告和部分跟踪/隐私域名。若正常功能异常，先暂停对比，可加白名单或关闭“使用完整 anti-AD 规则库”切回精简模式。白名单优先于全部拦截规则。
- 默认维持原来的小红书、网易云音乐、百度地图范围；在暂停状态开启“扩展到所有应用”后，可统一处理其他应用经过系统 DNS 的请求。不是为每个应用分别维护广告库。
- 规则来源：[anti-AD](https://github.com/privacy-protection-tools/anti-AD)。anti-AD 的 MIT 原许可随 APK 提供，界面内可查看。未复制 AdAway / DNS66 / personalDNSfilter 的引擎源码。

## 复测和诊断

更新后可在系统设置中强行停止目标应用，再重开复测开屏，同时检查登录、播放、图片、地图定位/路线等正常功能。

“检查过滤链路”验证静启自己的显式 DNS 查询，不证明目标应用也经过该路径。广告仍出现时，点击“开始 60 秒广告复现记录”，选择应用；广告出现后返回，点击“结束记录 / 查看诊断报告”，可预览和复制。不会自动发送。最多记录 600 条，60 秒停止采样；普通日志最多 120 条。记录在本机内存中，服务进程退出后丢失。报告包含域名、设备/应用版本、规则、状态和计数，不能归属具体页面。

## 能力边界

这是 DNS 域名过滤，不控制其他应用的摇一摇传感器，也不是 HTTPS 内容过滤。完整库仍可能漏拦自带 DoH/HTTPDNS、直接 IP、广告缓存和正常业务共用接口的广告。不能保证全部开屏广告消失。

只路由虚拟 DNS 地址，支持客户端 UDP DNS 的 A/AAAA 等问题，上游截断时 TCP 重试。尚不支持客户端直接 TCP DNS。普通 IPv4 / IPv6 连接直接走系统网络，不是全流量代理。

排查模式与日常过滤共用规则和过滤流程，只增加记录，不会自动重启过滤、添加规则或清除广告缓存。

## 数据与网络

无账号、遥测、日志上传、远程控制、证书安装、无障碍权限和广告 SDK。诊断日志仅内存保存；规则和设置存在应用私有目录，禁止备份。规则更新向 GitHub 下载公开域名文件，不上传请求记录。

未拦截 DNS 查询发往阿里公共 DNS 223.5.5.5:53，失败后尝试腾讯公共 DNS 119.29.29.29:53，使用普通 DNS，因此上游和网络运营者可能看到查询域名。私人 DNS 可能绕过本软件，界面会提示。

## 构建

JDK 17、Gradle 8.7、AGP 8.6.1、Android SDK Platform 35。设置 JAVA_HOME 和 local.properties 中的 sdk.dir。工作区 .tooling 为本次准备的本地构建工具链，不纳入源码版本管理。

Windows：powershell -ExecutionPolicy Bypass -File .\build.ps1

只执行核心测试：powershell -ExecutionPolicy Bypass -File .\build.ps1 -TestOnly

构建脚本执行规则/订阅/DNS 核心测试、assembleDebug、lintDebug，并复制 APK 到 dist。APK 使用本机 Android Debug 测试签名，可覆盖此前同签名版本。长期公开发布应改为专用发布签名并保存密钥。

核心测试共 10122 次检查（含 10000 组异常报文输入），另有完整订阅、实际广告域名、保留业务域名、白名单、订阅容错和大小上限检查。没有连接真机/模拟器，未声称完成 Android 更新流程、耗电或广告效果验证。

0.2.1 另提供 Android 专用的 IdleWaitInstrumentation 测试，覆盖空闲阻塞、停止唤起、先停止后等待、数据到达唤起和重复关闭。测试 APK 由 `gradlew.bat assembleDebugAndroidTest` 构建；当前只完成编译，未在设备执行。连接测试设备、安装主 APK 和测试 APK 后可运行：`adb shell am instrument -w cn.quietstart.test/cn.quietstart.IdleWaitInstrumentation`。主 APK 不包含测试入口。
